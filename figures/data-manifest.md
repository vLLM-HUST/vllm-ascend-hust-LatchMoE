| Figure | Purpose | Chart type | Required data |
|---|---|---|---|
| F1: Motivated example | Show graph-boundary failure and SEW replay-safe state update. | Vector mechanism diagram plus log callouts. | Failure signatures and SEW graph-capture evidence. |
| F2: System overview | Explain SEW modules and state objects. | Vector architecture diagram. | Method skeleton and code/module mapping. |
| F3: End-to-end performance | Show TTFT/TPOT/throughput under same workload and budget. | Grouped bars or small multiples. | `e1_end_to_end.csv`. |
| F4: Memory and slot sensitivity | Show HBM/KV/slot tradeoff and performance sensitivity. | Line plot plus stacked memory bars. | `e5_slot_sensitivity.csv`, `e2_memory_graph.csv`. |
| F5: B2 prefill behavior | Show active experts, waves, H2D, and TTFT under long prompts. | Line/grouped bars. | `e3_b2_prefill.csv`. |
| F6: Ablation | Attribute graph replay, B2 waves, transfer-aware scheduling, CPU-first loading. | Grouped bars/table hybrid. | `e4_ablation.csv`. |
| F7: Correctness/concurrency appendix | Show low-concurrency stability and semantics guard. | Table or compact bars. | `e6_correctness.csv`, concurrency run dirs. |
