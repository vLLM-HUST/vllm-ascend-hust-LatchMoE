\section{Related Work}
\label{sec:related}

\paragraph{Sparse MoE inference.}
Sparsely gated MoE models increase parameter capacity while activating a
subset of experts for each token
~\cite{shazeer2017outrageously,fedus2022switch,du2022glam,rajbhandari2022deepspeedmoe}.
Systems for large MoE models also combine routing with model and expert
parallelism~\cite{rajbhandari2022deepspeedmoe,li2023lina}. LatchMoE does not
change the model, router, or expert computation. It addresses the runtime
storage interface used when expert weights cannot remain fully resident on one
accelerator.

\paragraph{Expert offloading and scheduling.}
Expert-offloading systems reduce host-to-device movement or its exposed cost
through caching, prediction, prefetching, mixed precision, fine-grained
placement, and pipelined execution
~\cite{hwang2024pregated,xue2024moeinfinity,kong2024swapmoe,song2024promoe,tang2024hobbit,cao2025moelightning,fang2025klotski,li2026commitmoe}.
Recent CPU--GPU hybrid serving also stream-loads MoE prefill weights and
overlaps CPU and GPU work, while FlexGen coordinates heterogeneous placement
for dense models~\cite{cloudmoe2026,flexgen}. These systems decide which work or
weights to place, retain, and move. LatchMoE addresses an orthogonal execution
constraint: changing a cache decision must not change the weight storage bound
to replayed expert computation. Its placement interface therefore feeds fixed
slots and versioned leases instead of becoming part of the captured ABI.

\paragraph{Graph-based inference execution.}
Nimble compiles dynamic neural-network execution~\cite{kwon2020nimble}, while
FlashInfer provides graph-oriented mechanisms for customizable LLM inference
~\cite{ye2025flashinfer}. GraCE uses compiler transformations to
increase graph coverage~\cite{grace2026}. vTensor decouples computation from
physical-page management while exposing a continuous virtual address
~\cite{vtensor2024}, while ECHO makes dynamic KV-cache eviction and recall
graph-friendly~\cite{echo2026}. LatchMoE instead
manages executable weights selected by a captured router and ordered against
transfer and MLP computation. An eager seam exposes a fixed slot/map ABI to the
downstream graph.

\paragraph{Positioning.}
LatchMoE joins dynamic placement with graph replay by separating logical
ownership from graph-visible allocation and checking each ownership
interval as a lease. UVA alone supplies neither bounded HBM replacement nor
ready-before-publication and release-before-reuse ordering.
